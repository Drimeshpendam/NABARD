# NABARD Grade A Phase I Merit-Section Deep Analysis

This note is based on open-source, memory-based PYQ analysis from 2021–2025. NABARD does not officially release papers, so use these as preparation signals—not exact predictions.

## Core finding

Phase I merit is not generic GK.

```text
GA 20 + ESI 40 + ARD 40 = 100 merit marks
```

The highest-return preparation is:

1. Scheme architecture and current updates
2. Rural credit / financial inclusion / NABARD-linked institutions
3. ARD static fundamentals that repeat every year
4. Reports, indices, Budget and Economic Survey facts
5. Speed discipline: around 27–30 seconds per merit question

| Rural development | ~7% | 2–4 | MGNREGA guidelines, housing, Panchayat/institutions |

| Remaining cluster | ~12% | 4–6 | Fisheries, forestry, engineering, extension, meteorology, ecology |

### 2025 lesson

ARD was spread across roughly 20 chapters. Do not over-prepare only agronomy. The reliable static blocks are soil, animal husbandry and horticulture; the largest block is current-linked schemes/updates.

Year-wise signals:

- **2025:** schemes, reports, MSME, land records and NABARD’s own surveys dominated.

- **2023:** the paper was strongly scheme-driven.

## GA — 20 questions

Recent GA is mostly current affairs, but NABARD filters it toward banking, rural economy and institutions.

2024 observed split:

| Area | Questions |
|---|---:|
| Banking and finance | 7 |
| General/national/static GA | 6 |
| Schemes | 4 |
| ESI current affairs | 2 |
| Agriculture current affairs | 1 |
| **Total** | **20** |

Prepare the last six months deeply, but keep 9–10 month rural/agri/finance affairs alive.

## Question formats and seconds target

| Question type | Example | Target time |
|---|---|---:|
| Direct factual | KCC introduced in 1998 | 20–25 sec |
| Scheme feature/ministry/beneficiary | PMFBY premium or component | 30–40 sec |
| Statement combination | Which of (i), (ii), (iii) is correct? | 40–50 sec |
| Order/rank/threshold | Production order, seed chain, wage-material ratio | 45–60 sec |
| Numerical/data | MSME limit, crop estimate, rate, fund amount | 60–75 sec |

Skip and return if a merit-section question exceeds **50–60 seconds** on the first pass.

## Most reliable preparation rule

For every scheme, institution, or report, learn:

```text
Name → ministry/issuer → year → objective → beneficiary → component → latest data/update
```

For every static ARD concept, learn:

```text
Term → definition → classification → one real example → trap pair
```
