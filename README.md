# NABARD Grade A — RDBS General

Study workspace for NABARD Grade A Assistant Manager (RDBS), prepared for a B.Sc. Agriculture fresher.

## Folder map

| Folder | Purpose |
|---|---|
| `00_Overview` | Exam pattern, eligibility, targets, plan, progress tracker — start here |
| `01_Phase1_Aptitude` | Reasoning, Quant, English, Computer, Decision Making — qualifying sections |
| `02_Phase1_Merit_ESI_ARD_GA` | GA, Economic & Social Issues, Agriculture & Rural Development — merit sections |
| `03_Mains_English` | Descriptive English: essay, précis, report/letter practice |
| `04_Mains_ESI_ARD` | Objective + descriptive answer-writing for ESI and ARD |
| `05_PYQs` | Previous-year patterns, memory-based questions, exam analysis |
| `06_Mocks_and_Practice` | Mock logs, sectional tests, error notebook |
| `07_Interview` | NABARD awareness, agriculture/rural-development interview prep |
| `08_Resources` | Book list, source list, references |
| `dashboard` | React dashboard for plan tracking, notes, quizzes, and scores |

## Workflow

1. Read `00_Overview/Exam_Pattern.md` first — Phase I shortlisting uses only GA + ESI + ARD.
2. Read `00_Overview/Target_Chart.md` and convert it into your personal score target.
3. Follow `00_Overview/Study_Plan.md`; update `00_Overview/Progress_Tracker.md` weekly.
4. Every mock or quiz goes into `06_Mocks_and_Practice/Error_Log.md`.
5. Start descriptive practice early — final merit is driven by Mains + Interview.

## Dashboard

```powershell
cd dashboard
npm install
npm run dev
```

The dashboard reads Markdown files directly from this workspace and saves progress locally in the browser.
