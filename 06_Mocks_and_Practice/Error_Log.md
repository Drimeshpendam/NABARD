# Error Log

The error log is the highest-value artifact. Every wrong or guessed answer goes here.

## Format

```text
Date:
Source/mock:
Question/topic:
My answer:
Correct answer:
Why I missed it:
Rule/reminder:
Retest date:
```

## Error categories

- Knowledge gap
- Formula/rule forgotten
- Scheme/ministry confusion
- Current affairs miss
- Reading error
- Calculation error
- Guessing under pressure
- Descriptive structure problem

## Weekly routine

1. Sort errors by section.
2. Rewrite the rule for the top 10 misses.
3. Retest after 3 days.
4. Mark an error **cleared** only after getting it right twice.
